# Syntecxhub_Portfolio_Website

A responsive **Portfolio Website** developed as part of my **Frontend Web Development Internship at Syntecxhub** using **HTML5 and CSS3**.

The project focuses on creating a clean, structured, and professional portfolio interface for presenting personal information, skills, projects, and other professional details through a responsive web layout.

## 📌 Project Overview

**Syntecxhub_Portfolio_Website** is a frontend portfolio website created during my internship at **Syntecxhub**.

The project provided practical experience in designing and developing a professional personal portfolio from scratch while applying core frontend development concepts such as semantic HTML, CSS styling, responsive layouts, website structuring, and user-focused interface design.

* 👨‍💻 Professional portfolio interface

## 🚀 How It Works

The portfolio website is built using HTML5 and CSS3.

* **HTML5** defines the structure and content of the portfolio.
* **CSS3** handles the visual presentation, layout, spacing, typography, and responsive behaviour.
* The website organizes professional information into a structured portfolio format that can be viewed directly through a web browser.

## 💻 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/shayab-dev/Syntecxhub_Portfolio_Website.git
```

### 2. Navigate to the Project Directory

```bash
cd Syntecxhub_Portfolio_Website
```

### 3. Run the Website

No backend server, database, or package installation is required.

Simply open:

```text
index.html
```

in your web browser.

For development, you can also use **VS Code Live Server**.
